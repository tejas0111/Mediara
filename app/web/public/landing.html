Walrus Memory

Teach once, kept on Walrus

Every fact is stored as a sealed blob on Walrus Mainnet and recalled before each reply — with a public receipt for every line.

STOP guard

Unsafe answers never send

A rule-based guard runs before the model: allergy conflicts and drug interactions are blocked by drug class and cite the exact stored fact.

Proof, not claims

Every block is verifiable

Each STOP lands in a hash-chained guard-proof ledger with the recalled fact and blob id — re-verified on every view, printable for the doctor.

Measured, not promised: memory changes the outcome on 12/12 adverse probes with 0 false positives on safe ones. Try the shared demo in the app — ask what she avoids, then ask for ibuprofen and watch it STOP.

Confirm with your doctor — Mediara is not medical advice. Safety checks run before every answer.
